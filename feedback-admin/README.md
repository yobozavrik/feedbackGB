# 📊 Галя слухає — FeedbackGB (Admin App)

Адміністративна панель керування, аналітики та модерації для проекту **FeedbackGB**.

Призначена для керівників, супер-адмінів та територіальних менеджерів мережі «Галя Балувана». Дозволяє відстежувати фідбек у реальному часі, відповідати продавчиням, керувати списками користувачів, аналізувати метрики та вивантажувати звіти.

---

## ✨ Особливості адмін-панелі

- 📊 **Моніторинг фідбеку**: зручна стрічка відгуків з фільтрацією за категоріями, магазинами, статусами та продавчинями.
- 💬 **Система коментарів**: можливість залишати відповіді на відгуки продавчиням з автоматичною доставкою сповіщення в Telegram (захищено від HTML-ін'єкцій).
- 📈 **Аналітика та вирви**: сторінки аналізу конверсії, популярних проблем та активності торгових точок.
- 🗂 **Керування користувачами**: додавання продавчинь та менеджерів, керування правами доступу та безпечне скидання PIN-кодів.
- 🖨 **Експорт звітів**: вивантаження даних у форматі CSV/JSON для подальшого аналізу.
- 🛡 **Лог аудиту**: запис усіх дій адміністраторів (`audit_log`) для запобігання несанкціонованим змінам.
- 🛡 **Розподілений Rate-Limit**: Захист PIN-входу за допомогою Supabase Postgres збереженої процедури з fail-closed поведінкою у продакшні.

---

## 💻 Стек технологій

- **Next.js 14 (App Router)** + TypeScript
- **Ant Design (Pro Components)** — преміальний професійний інтерфейс адмін-панелі
- **Tailwind CSS**
- **`@supabase/supabase-js`**
- **Vitest** (Unit тести)

## ⚙️ Локальний запуск

1. Перейдіть до папки адмін-панелі:
   ```bash
   cd feedback-admin
   ```
2. Скопіюйте файл налаштувань:
   ```bash
   cp .env.example .env.local
   ```
3. Заповніть змінні в `.env.local`:
   - `NEXT_PUBLIC_SUPABASE_URL` та `NEXT_PUBLIC_SUPABASE_ANON_KEY`
   - `SUPABASE_SERVICE_ROLE_KEY` (обов'язковий для адмін-функцій та логів аудиту)
   - `SESSION_SECRET` (мінімум 16 символів)
4. Встановіть залежності та запустіть сервер розробки:
   ```bash
   npm install
   npm run dev
   ```

---

## 🚀 Деплой на Vercel

1. Підключіть репозиторій у Vercel.
2. Вкажіть **Root Directory** як `feedback-admin`.
3. Переконайтеся, що **Framework Preset** вибрано як **Next.js**.
4. Додайте змінні оточення у **Environment Variables** проекту Vercel.
   > [!IMPORTANT]
   > Обов'язково вкажіть `SUPABASE_SERVICE_ROLE_KEY` та `SESSION_SECRET` (довжиною не менше 16 символів). У продакшн-середовищі відсутність цих ключів призведе до fail-fast блокування входу (помилки 500/503) з міркувань безпеки.
