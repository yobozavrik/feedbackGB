# Макеты: «Мережа → Графік відсутностей»

**Основа:** существующий дизайн админки — `AdminPageContainer`, Ant Design `Tabs`, `Card`, `Table`, `Tag`, текущая палитра светлой/тёмной темы. Новых шрифтов, градиентов или отдельного визуального языка нет.

## Общая навигация

```text
Мережа
└─ Графіки роботи
└─ Графік відсутностей
   ├─ Заявки                 ← Kanban HR
   ├─ Календар відсутностей  ← подтверждённые записи
   └─ Список                 ← полный журнал и отмены
```

## Вариант A — операционный Kanban (рекомендуется)

> **Затверджено 22.09.2026.** Цей варіант реалізовується. Варіанти B і C лишаються довідковими альтернативами.

Подходит для ежедневной работы HR: все четыре этапа видны одновременно.

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│ Графік відсутностей                                                          │
│ Відпустки, лікарняні, відгули та переведення продавчинь магазинів            │
├──────────────────────────────────────────────────────────────────────────────┤
│ [ Заявки ] [ Календар відсутностей ] [ Список ]                              │
├──────────────────────────────────────────────────────────────────────────────┤
│ [Усі типи ▾] [Усі магазини ▾] [Усі продавці ▾] [Вересень 2026 ▾] [Без рішення]│
├──────────────────┬──────────────────┬──────────────────┬────────────────────┤
│ Отримано · 4     │ На розгляді · 2  │ Погоджено · 5    │ Відхилено · 1      │
│                  │                  │                  │                    │
│ ┌──────────────┐ │ ┌──────────────┐ │ ┌──────────────┐ │ ┌──────────────┐   │
│ │ 🏖️ Яна П.   │ │ │ 🤒 Юлія М.  │ │ │ 🛋️ Оля К.   │ │ │ 🏖️ Марина Р. │   │
│ │ Роша         │ │ │ Шкільна      │ │ │ Київ         │ │ │ Герцена      │   │
│ │ 12–18.10     │ │ │ 21–? .09     │ │ │ 25.09        │ │ │ 01–03.10    │   │
│ │ Нове · 25 хв │ │ │ Фото довідки │ │ │ Absence #124 │ │ │ Причина: …   │   │
│ └──────────────┘ │ └──────────────┘ │ └──────────────┘ │ └──────────────┘   │
└──────────────────┴──────────────────┴──────────────────┴────────────────────┘
```

Карточка перетаскивается только после подтверждения. При переносе в «Погоджено» открывается модалка проверки периода и создания отсутствия.

`resignation` в цю дошку не потрапляє. Відхилення завжди має текстову причину: її видно в картці та продавцю в історії його заявки.

## Вариант B — Kanban с отдельной панелью деталей

Подходит, когда заявка содержит фото справки, длинные комментарии и историю.

```text
┌───────────────────────────────────────────────┬──────────────────────────────┐
│ Канбан: Отримано / На розгляді / Погоджено…   │ Заявка Яна П.                 │
│                                               │ 🏖️ Відпустка · Роша           │
│ [карточки в четырёх колонках]                 │ 12.10.2026 — 18.10.2026       │
│                                               │                               │
│                                               │ Коментар продавчині            │
│                                               │ «Планую поїздку…»              │
│                                               │                               │
│                                               │ [Взяти в роботу]               │
│                                               │ [Погодити та створити          │
│                                               │  відсутність]                  │
│                                               │ [Відхилити]                    │
│                                               │                               │
│                                               │ Історія:                       │
│                                               │ 09:40 отримано                 │
│                                               │ 10:15 призначено HR            │
└───────────────────────────────────────────────┴──────────────────────────────┘
```

Преимущество: Kanban не перегружен. Выбранная карточка открывает существующий тип drawer/side panel админки, а не новую визуальную сущность.

## Вариант C — компактный режим для узкого экрана

На телефоне/узком окне колонки не сжимаются до нечитаемого состояния.

```text
┌───────────────────────────────┐
│ Графік відсутностей            │
│ [ Заявки ▾ ]                   │
│ [ Отримано · 4 ▾ ]             │
│ [Усі типи] [Фільтр]            │
├───────────────────────────────┤
│ 🏖️ Яна П.                      │
│ Роша · 12–18.10                │
│ Отримано · 25 хв тому          │
│ [Відкрити]                     │
├───────────────────────────────┤
│ 🤒 Юлія М.                     │
│ Шкільна · з 21.09              │
│ Потрібна дата завершення       │
└───────────────────────────────┘
```

Переключатель колонки заменяет горизонтальный drag. Все переходы остаются через ту же модалку подтверждения.

## Состояния и цвета

Используются существующие Ant Design теги:

- `new` / «Отримано» — синий;
- `in_progress` / «На розгляді» — золотой;
- `resolved` / «Погоджено» — зелёный;
- `rejected` / «Відхилено» — красный;
- отпуск — синий, больничный — красный, отгул — золотой, перевод — фиолетовый тег только для типа обращения.

Цвет не является единственным носителем смысла: на каждой карточке всегда есть текстовый статус.
