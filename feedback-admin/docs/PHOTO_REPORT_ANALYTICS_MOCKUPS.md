# Фото звіт: макеты новых вкладок

## Дизайн-правила

Макеты используют существующий каркас: `AdminPageContainer` с заголовком и табами, Ant Design `Card`, `Statistic`, `DatePicker`, `Table`, `Tag`, `Modal`. Цвета и отступы берутся из текущей темы Ant Design; отдельный sidebar, собственные кнопки или новый UI-kit не добавляются.

## Макет A — Контроль дня

```text
Фото звіт                                      [Дата: 15.09.2026] [Магазин]
Щоденний контроль надходження фото по активних магазинах

[ Виконано 38/52 ] [ Частково 4 ] [ Не виконано 1 ] [ Очікується 9 ] [ Звітів 71 ] [ Фото 426 ]

| Магазин     | Статус           | Звіти | Фото | Остання | Перегляд |
| Черемош     | [Виконано]       | 3 / 3 | 27   | 18:42   | Відкрити |
| Рута        | [Частково]       | 1 / 3 | 8    | 12:10   | Відкрити |
| Гравітон    | [Не виконано]    | 0 / 3 | 0    | —       | —        |
| Садова      | [Очікується]     | 0 / 3 | —    | —       | —        |
| Закритий    | [Не потрібно]    | 0 / 0 | —    | —       | —        |
```

Клик «Відкрити» использует уже существующую `Modal`-галерею с тем же фильтром `effective_at` и магазина, что и строка. Теги взаимоисключающие: «Не виконано» — есть `missed`, нет закрытых; «Частково» — есть `missed` и закрытые; «Виконано» — нет `missed`/`pending`; «Очікується» — нет `missed`, но есть `pending`. Четыре числа в шапке равны 52; «Не потрібно» вне знаменателя. Колонки «У зміні» и «Не надіслали» — только этап 6.

## Макет B — Профиль магазина

```text
Фото звіт / Магазини                         [Черемош] [Період: 30 днів]

[ Виконання 83% ] [ Днів з пропущеними вікнами 5 ] [ Днів без жодного звіту 2 ] [ 2.1 звіту / день ] [ 9 фото / звіт ]

Виконання контрольних вікон
Дата          1: Ранок   2: День   3: Вечір
15 вересня      ■           ■          ◌
14 вересня      ■           ▨          ■
13 вересня      □           □          □

■ вчасно   ▨ із запізненням   □ пропущено   ◌ очікується   — не потрібно

[столбцы: отчёты по дням]     [линия: целевое число отчётов]

| Дата | План / факт | Фото | Продавці | Останній звіт | Дія |
```

Заголовки строятся из настраиваемых `slot_no` и `slot_label`, а не фиксированных «Ранок/День/Вечір». В ячейке только статус одного окна: «частково» к ней не применяется.

## Макет C — Продавцы и смены

```text
Фото звіт / Продавці та зміни                [Дата] [Магазин] [Продавець]

[ У зміні 84 ] [ Надіслали 49 ] [ Закрито колегою 28 ] [ Не надіслали при відкритому вікні 7 ]

| Магазин | Продавець | Зміна        | Джерело | Звіти | Фото | Статус       |
| Черемош | Лариса М. | 09:00–18:00  | check-in| 2     | 18   | [Надіслав]   |
| Черемош | Марія М.  | 12:00–21:00  | ручне підтвердження | 0 | 0 | [Вікно закрито колегою] |
| Гравітон| Олена К.  | 10:00–19:00  | check-in| 0     | 0    | [Не надіслав при відкритому вікні]|

Журнал дня: 09:00 початок зміни → 12:14 звіт (9 фото) → 18:00 кінець зміни
```

Poster здесь не является текущим источником: он возможен только после отдельной интеграции. Импорт расписания (`kind=planned`) не считается присутствием. Для строки без подтверждённой фактической смены нельзя показывать «не надіслав»: только нейтральное «немає даних про зміну».

## Поведение на мобильном экране

На ширине 375px используются `Table` с `expandable`: в строке остаются магазин, Tag-статус и действие; факт/план, продавцы, смена и время — в раскрываемой панели. Галерея остаётся в текущем адаптивном `Modal`.
