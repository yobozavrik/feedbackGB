## P-01 — ленивая загрузка «Звіти» магазинов

- Server page `/admin/stores` теперь читает только `v_stores`. Вкладка `Звіти` при первом открытии вызывает защищённый `/api/admin/stores/reports`.
- API поддерживает период 60/90/180 дней, лимит до 1000 записей на страницу, страницы 1–10 и один серверный `as_of` для всех страниц. При превышении 10 000 записей UI показывает ошибку, чтобы не отображать заниженные счётчики.
- PIN-хэш запрашивается только серверной частью API для вычисления `has_pin`; в JSON не передаётся.
- Пять полных перезагрузок локального `/admin/stores`: текст inline `<script>` каждый раз 17 630 символов. Это на 242 870 символов (около 93%) меньше Preview-версии на тех же данных. Метрика не является размером сетевого ответа.
- Локальный авторизованный UI: 26 карточек магазинов; до открытия «Звіти» запросов API отчётов нет; первое открытие дало один запрос, повторное открытие не дало нового; таблица показывает 26 магазинов.
- Выборочное сравнение с Preview в один сеанс: Кварц — 41, Шкільна — 12 в колонке 30д в обеих версиях.
- Неавторизованный `GET /api/admin/stores/reports` на локальном production server: HTTP 401 от middleware.
- `npm.cmd run typecheck` прошёл; целевой Vitest — 4/4; полный Vitest — 286/286; production build прошёл. Три прежних lint-предупреждения остались в графиках/отсутствиях.
