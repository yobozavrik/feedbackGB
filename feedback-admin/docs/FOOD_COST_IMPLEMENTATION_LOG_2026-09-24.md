Дополнительно для нового write-маршрута Production требует настроенный `CRON_SECRET`, иначе 503 — не полагается на резервную проверку заголовка `x-vercel-cron`. Без production deploy расписание ещё не действует; наличие секрета в локальном `.env` проверено только как boolean и **не доказывает**, что он задан в Vercel Production. Контроль реального первого запуска — логи Vercel, полный `processedCells=78` и DB-readback. Cron не должен считаться принятым только по конфигурации.
