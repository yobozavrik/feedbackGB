# 📱 Галя слухає — FeedbackGB (Sellers App)

Внутрішній **Telegram Mini App** для команди продавчинь «Галя Балувана».

Швидкий, гарний і інтуїтивний інструмент зворотного зв'язку: продавчиня відкриває кнопку в робочому чаті — й одразу може повідомити, чого не вистачає на полицях, які є проблеми постачання, або надіслати фото дефектів тощо.

---

## ✨ Особливості клієнтського додатку

- 🛒 **6 категорій фідбеку**: відсутні товари, проблеми постачання, ідеї, «підгледіла десь», технічні поломки, голос клієнта.
- 📷 **Фото з камери**: стиснення зображень на стороні клієнта до $\le 1600\text{px}$ JPEG перед завантаженням.
- 🪪 **Telegram Auth**: Автоматична безпечна ідентифікація продавчині через Telegram WebApp `initData` з HMAC-валідацією на сервері проти `TELEGRAM_BOT_TOKEN`.
- 🗄 **База даних**: збереження відгуків у схемі `feedbackgb` Supabase Postgres, фото завантажуються в бакет `feedback-photos`.
- 📦 **POS Каталог**: інтеграція з асортиментом товарів через сутності категорій та вью популярних товарів.
- 🛡 **Розподілений Rate-Limit**: Захист від брутфорсу та спаму за допомогою збереженої процедури в Supabase з fail-closed поведінкою в продакшні.

---

## 💻 Стек технологій

- **Next.js 14 (App Router)** + TypeScript
- **Tailwind CSS** — пастельна палітра (blush / peach / lavender / mint)
- **`@supabase/supabase-js`**
- **Telegram Web App SDK**
- **Vitest** (Unit тести)

## ⚙️ Локальний запуск

1. Перейдіть до папки клієнтського додатку:
   ```bash
   cd feedback-app
   ```
2. Скопіюйте файл налаштувань:
   ```bash
   cp .env.example .env.local
   ```
3. Заповніть змінні в `.env.local`:
   - `NEXT_PUBLIC_SUPABASE_URL` та `NEXT_PUBLIC_SUPABASE_ANON_KEY`
   - `TELEGRAM_BOT_TOKEN`
   - `SESSION_SECRET` (мінімум 16 символів)
4. Встановіть залежності та запустіть сервер розробки:
   ```bash
   npm install
   npm run dev
   ```

---

## 🚀 Деплой на Vercel

1. Підключіть репозиторій у Vercel.
2. Вкажіть **Root Directory** як `feedback-app`.
3. Переконайтеся, що **Framework Preset** вибрано як **Next.js**.
4. Додайте всі змінні з файлу `.env.example` у **Environment Variables** проекту Vercel.
   > [!IMPORTANT]
   > Переконайтеся, що `SESSION_SECRET` вказано довжиною не менше 16 символів. В іншому випадку в продакшні авторизація впаде з помилкою 500 для безпеки.
