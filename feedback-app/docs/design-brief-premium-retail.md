# ТЗ для Клод Дизайн: премиализация FeedbackGB для продажи в фудритейл-сети

## Контекст

FeedbackGB сейчас — внутренний инструмент для одной сети («Галя Балувана»): Telegram Mini App для продавщиц + админка на Ant Design для менеджмента. Технически сделано аккуратно (Next.js 14, Tailwind с токенизированной палитрой, Vitest, Supabase), но визуально это «внутренний тул», а не продукт, который можно продать как white-label SaaS другим ритейл-сетям.

Задача: довести дизайн до уровня, при котором продукт можно показывать на демо закупщикам сетей (категорийным менеджерам, операционным директорам) как премиальное коммерческое решение, а не самописку.

## Текущее состояние (для отправной точки)

- **Клиент** (`feedback-app/src/styles/globals.css`, `tailwind.config.ts`): CSS-переменные `--brand-500/600/50`, `--ink-900/700/500/300`, 8 цветов категорий `--cat-*`, карточки с `shadow-soft`, анимации `fade-up/pop/shimmer/shake`. Иконки категорий — голые emoji. Шрифты уже подключены (Inter для текста, Manrope для display), но используются нейтрально, без выраженного брендового почерка.
- **Админка** (`feedback-admin`): `@ant-design/pro-components` ProLayout из коробки, дефолтная антд-тема, без кастомизации token-системы антд под бренд.
- Нет логотипа, нет фирменного знака, нет brand guideline, нет multi-tenant theming (продукт жёстко заточен под один бренд).

## Цель

Премиум B2B SaaS-продукт «обратная связь с торгового зала» для сетей фудритейла (супермаркеты, дарксторы, пекарни-сети), который можно:
1. Показать на sales-демо и не стыдиться внешнего вида рядом с конкурентами уровня enterprise retail tech;
2. White-label под бренд каждой сети-клиента (цвета, логотип, название) без переписывания кода;
3. Использовать одновременно как Telegram Mini App (для продавщиц на полу) и как полноценную web-админку (для менеджеров/категорийщиков).

## Что нужно сделать

### 1. Brand & design system
- Фирменный логотип/wordmark продукта (рабочее имя сейчас — «Галя слухає», нужно отделить product brand от brand клиента-сети).
- Расширить токенную систему: добавить semantic-слой поверх текущих CSS-переменных, чтобы каждый клиент (сеть) мог переопределить `--brand-*` через свою тему без правки компонентов.
- Подобрать премиальную типографику (сейчас системные шрифты) — display-шрифт для заголовков категорий, текстовый для основного контента.
- Заменить emoji-иконки категорий (🛍️📷🔧 и т.д.) на консистентный кастомный icon-set (line/duotone, в стиле бренда) — 8 категорий фидбека + UI-иконки.

### 2. Mobile/Telegram Mini App (feedback-app)
- Редизайн главного экрана (`CategoryGrid.tsx`) — сейчас карточки функциональны, но плоские; нужна более выразительная иерархия (приоритетные категории vs «+Інше»), микро-иллюстрации/паттерны на карточках.
- Экран формы фидбека (`FeedbackForm.tsx`, `PriorityFeedbackForm.tsx`) — премиальные состояния загрузки фото, прогресс, success-state.
- Пустые/ошибочные состояния, офлайн-баннер (`OfflineQueueBanner.tsx`) — сделать их частью единого визуального языка, а не системными алертами.
- Сохранить ограничения Telegram WebApp (нативные жесты, безопасные зоны, цвета темы Telegram) — дизайн должен жить и в light, и в Telegram dark theme.

### 3. Admin/management dashboard (feedback-admin)
- Кастомизировать Ant Design 5 theme tokens под brand (сейчас дефолтный синий ProLayout) — sider, header, ProTable, графики (`DashboardKPI`, `DashboardHeatmap`, `DashboardSignals`).
- Разработать премиальный дашборд для категорийных менеджеров/операционных директоров: KPI-карточки, heatmap проблемных точек по магазинам, voice-of-customer лента — это то, что реально продают закупщику на демо.
- Multi-tenant: визуальный механизм переключения/брендирования под клиента (логотип сети в шапке, акцентный цвет).

### 4. Sales-facing материалы (опционально, если есть бюджет)
- Лендинг/демо-страница продукта для презентации сетям (не для продавщиц) — отдельно от рабочего приложения.
- Набор скриншотов/мокапов «было/стало» для коммерческого предложения.

## Ограничения и контекст, которые нужно учитывать

- Стек фиксирован: Next.js 14 App Router + Tailwind (клиент), Next.js + Ant Design 5 + Pro Components (админка). Дизайн должен быть реализуем в этом стеке без смены библиотек.
- Mini App работает внутри Telegram WebView — учитывать его UI-ограничения (нет полноценного browser chrome, safe area, системная тема).
- Целевые пользователи двух типов: продавщицы на полу (быстро, на бегу, часто в перчатках/с одной рукой — мобильный UX должен быть очень простым) и менеджеры/закупщики (десктоп, привыкли к BI-инструментам уровня enterprise).
- Должна сохраниться текущая функциональность (8 категорий фидбека, фото с камеры, офлайн-очередь, rate-limiting UX) — это редизайн, не пересборка фич.

## Формат сдачи

Figma-файл с design system (токены, компоненты, иконки) + ключевые экраны в high-fidelity (mobile: главный экран, форма фидбека, успех; admin: дашборд, таблица фидбеков, карточка магазина) + краткие guidelines по white-label кастомизации под нового клиента.
