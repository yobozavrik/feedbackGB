# FeedbackGB — модули, вкладки и маршруты

Актуальный каталог экранов. Метка **заглушка** означает: маршрут и дизайн есть, но бизнес-данные/операции ещё не подключены.

## 1. Приложение продавца (`feedback-app`)

| Раздел | Маршрут | Что делает |
|---|---|---|
| Главная | `/` | показывает приоритетные карточки, HR и другие категории |
| Форма обращения | `/feedback/[category]` | создаёт обращение выбранной категории |
| Продукция магазина | `/products-menu` | поток нехватки, избытка и брака с выбором товара |
| Фото звіт | `/feedback/photo_report` | отправка фотозвита для основного магазина или разрешённой замены |
| HR | `/hr-menu/*` | отдельные формы отпуска, отгула, больничного, перевода и увольнения |
| Мои обращения | `/my-requests` и `/my-requests/[id]` | просмотр собственных обращений |
| Уведомления | `/notifications` | уведомления продавца |
| Вход | `/login` | PIN-вход |

### 1.1 Категории обращений

`shared/lib/categories.ts` содержит общий каталог: нехватка товара, избыток, брак, проблема поставки, идея, увиденное у других, ремонт, голос клиента, расходные материалы, HR и фотозвит. Для каждой категории в коде зафиксированы поля формы и правила валидации.

### 1.2 Фото звіт

- На главной это отдельная приоритетная карточка.
- Продавец видит свой основной магазин как текущий. Если у него есть активные разрешения на замену, ниже доступен список «Працюю на заміні».
- Сервер перепроверяет выбранный магазин: допускается основной магазин либо активное разрешение `seller_store_permissions`.
- Один отчёт должен содержать от **6 до 15** фотографий. Проверка выполняется и в интерфейсе, и на сервере.
- Фотографии сохраняются в private Storage; частичная загрузка очищается, чтобы не оставлять сиротские файлы.

## 2. Админ-панель (`feedback-admin`)

### 2.1 Раздел «Робота»

| Вкладка | Маршрут | Состояние |
|---|---|---|
| Огляд | `/admin` | рабочий операционный обзор и поток обращений |
| Мої завдання | `/admin/tasks` | рабочая вкладка назначенных обращений |
| Фотозвіт | `/admin/photo-report` | рабочая аналитика, контроль дня и галерея |

«Фотозвіт» показывает агрегаты по магазинам и продавцам, дневной контроль, тепловые карты и галерею подписанных URL. Во вкладке «Магазини» доступны быстрые периоды 7, 14 и 30 дней, а также свой период до 31 календарного дня. Красный/жёлтый/зелёный в тепловой карте отражает число отправленных отчётов, а не подтверждённое присутствие сотрудника. Данные `photo_report_seller_daily` показывают продавцов, которые действительно отправляли звиты в этот день.

### 2.2 Раздел «Мережа»

| Вкладка | Маршрут | Состояние |
|---|---|---|
| Магазини | `/admin/stores` | рабочий справочник и показатели магазинов |
| Співробітники | `/admin/users` | создание/редактирование учётных записей, PIN и доступы замен |
| Графіки роботи | `/admin/network/schedules` | рабочее планирование смен магазинов |
| Графік відсутностей | `/admin/network/absences` | реестр отпусков, больничных и отгулов |

`Графіки роботи` состоит из трёх представлений: «Сітка місяця», «Статистика» и «Заміни». В сетке сверху идут магазины, слева — даты, в ячейке — ФИО продавца. Субботы, воскресенья и украинские праздники подсвечены как календарный ориентир; сеть работает 7 дней, поэтому это не выходные в данных.

### 2.3 Разделы «Аналітика» и «Система»

| Вкладка | Маршрут | Доступ |
|---|---|---|
| Кліки | `/admin/analytics` | super_admin |
| Воронка | `/admin/funnel` | super_admin |
| Журнал дій | `/admin/audit` | super_admin |
| Інструменти | `/admin/tools` | admin / super_admin |
| Налаштування | `/admin/settings` | admin / super_admin |

### 2.4 Раздел «Виробництво»

| Вкладка | Маршрут | Состояние |
|---|---|---|
| Графіки роботи | `/admin/production/schedules` | **заглушка**, данных нет |
| Цехи | `/admin/production/workshops` | **заглушка**, справочник не подключён |
| Постачання | `/admin/production/supplies` | **заглушка**, workflow не подключён |

Все три страницы доступны только `super_admin`. Нельзя использовать их как источник факта о производстве, пока не появятся утверждённые источники и миграции.

## 3. Основные API-группы

| Группа | Ответственность |
|---|---|
| `/api/auth/*` | вход, выход, текущая сессия, доступные магазины фотозвита |
| `/api/feedback` | создание и чтение обращений продавца |
| `/api/hr/*` | HR-заявки продавца |
| `/api/my-feedback/*` | собственные обращения продавца |
| `/api/admin/feedback/*` | обработка обращения, комментарии, фотографии |
| `/api/admin/users/*` | сотрудники, PIN, разблокировка и разрешения замен |
| `/api/admin/photo-report/*` | контроль, аналитика и галерея фотозвитов |
| `/api/admin/network/schedule-*`, `/schedules/*` | периоды, смены, статистика и замены |
| `/api/admin/network/absences` | реестр отсутствий |
| `/api/admin/analytics/*`, `/funnel` | продуктовая аналитика |
| `/api/admin/notifications/*` | уведомления администратора |
| `/api/cron/*` | ежедневные отчёты и зеркалирование фото |

Все `/api/admin/*` повторно проверяют административную сессию на сервере; нельзя считать защитой только скрытый пункт меню.
