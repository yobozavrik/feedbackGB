# ТЗ для Google Stitch — «Замовлення сировини» (supply-app / Галя)

## 0. Хто це і навіщо

Додаток називається **«Галя»** — внутрішній інструмент для співробітників
цеху та складу мережі пекарень/кондитерських/піцерій. Не для клієнтів, не
для менеджерів у офісі — для людини в цеху, часто з зайнятими або
борошнистими руками, яка за 10 секунд має знайти потрібний інгредієнт і
відправити заявку, поки не забула. Це не «ще один SaaS-дашборд» — це
робочий інструмент, який має відчуватись швидким, теплим і зрозумілим з
першого погляду, як хороший grocery-додаток, а не як складська 1С.

**Модуль:** «Замовлення сировини» — частина розділу «Сировина для цеху».
Потрібні макети 3 екранів (список нижче) в одному візуальному ключі.

**Платформа:** мобільний веб (Telegram Mini App), портрет, ширина ~375px
(iPhone SE / базовий Android). Десктоп не потрібен.

**Мова:** українська.

## 1. Референси (орієнтуйся на ці конкретні патерни)

Це не абстрактне «зроби красиво» — ось конкретні відомі продукти, чиї
прийоми треба взяти за основу:

- **Instacart** — пошук-первинний UX: великий search bar одразу під
  заголовком, категорії як другорядна навігація нижче, а не навпаки
- **Blinkit / Zepto (quick-commerce)** — компактні категорійні тайли з
  фото товару замість іконок/емодзі, дуже великі зони дотику навіть при
  маленькому розмірі тайла, відчуття швидкості й «встиг за хвилину»
- **Deliveroo / Wolt** — теплі, апетитні предметні фото їжі на чистому
  світлому фоні як мова категорій замість піктограм
- Загальний тон — **сучасний iOS consumer-додаток** (на кшталт Revolut
  чи Linear за чистотою верстки), а НЕ корпоративний ERP/адмінський
  дашборд і НЕ «складський» стиль з таблицями та дрібним текстом

## 2. Дизайн-токени (використати точно ці значення — це вже жива продакшн-система)

**Кольори (light theme, hex):**
| Роль | Токен | Hex |
|---|---|---|
| Фон сторінки | `bg` | `#F9F9FF` |
| Картка / поверхня | `elev` | `#FFFFFF` |
| Другий рівень (hover/active фон) | `elev-2` | `#F1F3FF` |
| Текст основний | `ink-900` | `#141B2B` |
| Текст вторинний | `ink-700` | `#434654` |
| Текст приглушений | `ink-500` | `#737686` |
| Бордер / плейсхолдер | `ink-300` | `#C3C5D7` (20–45% opacity) |
| Бренд-акцент | `brand-500` | `#1353D8` |
| Бренд-акцент, hover | `brand-600` | `#003FB1` |
| Бренд-акцент, світлий фон | `brand-50` | `#DBE1FF` |

**Сигнатурний акцент модуля (новий, тільки для «Сировини» — див. п.6):**
| Роль | Hex |
|---|---|
| Тепле «пшеничне» підсвічування (harvest amber) | `#C97C2B` |
| Світлий фон для нього | `#FBEBD7` |

**Типографіка:**
- Текст/UI: **Inter**
- Заголовки: **Manrope**, напівжирний
- Шкала: h1 екрана ~22px/bold · підзаголовок ~13-14px/regular · тіло
  картки ~15px/medium · дрібні підписи ~11-13px

**Форма й глибина:**
- Радіус карток: 12-16px (rounded-xl); дрібних елементів (фото-тайл,
  бейджі): 8px
- Тінь: дуже м'яка, розсіяна, майже непомітна (`0 1px 2px rgba(20,27,43,.05), 0 10px 28px rgba(20,27,43,.08)`) — НЕ різка card-shadow
- Бордер карток: `ink-300` @ ~20% opacity, товщина 1px
- Кнопки: висота 52px, rounded-lg, primary = заливка `brand-500` + білий
  текст, ghost = білий фон + бордер
- Tap-стан: легке scale-down (~97%), без різких ефектів, без bounce

## 3. Фото-арт-дирекшн для категорій (це головне, на чому зроби акцент)

**Ключова вимога: жодних емодзі в UI категорій.** Замість них — маленькі
фото-мініатюри товарів, як у Blinkit/Zepto/Deliveroo.

Специфікація фото (однакова для всіх 9, щоб сітка виглядала єдиним
набором, а не колажем із стоку):
- Квадратний кадр 1:1, тайл-розмір у макеті ~40×40px, радіус кута ~8px
- **Один інгредієнт-герой в кадрі** (не композиція з 5 продуктів) —
  напр. для «М'ясо та птиця» — один шматок куряче філе або стейк, для
  «Молочні продукти та сири» — головка сиру або пляшка молока
- Світле, майже біле тло (студійний food-фото стиль, як каталог
  Instacart/Prykoly, НЕ темний ресторанний moody-стиль)
- М'яке розсіяне студійне світло, легка природна тінь під продуктом —
  апетитно, чисто, без глянцевого «стокового» пластикового вигляду
- Однаковий ракурс зйомки (згори під легким кутом ~30-45°) і однакова
  відстань кадрування для всіх 9 — це критично для візуальної єдності
  сітки
- Без тексту, водяних знаків, брендингу на фото

Список категорій із конкретним героєм кадру для кожної:
1. **М'ясо та птиця** — шматок курячого філе або яловичий стейк
2. **Риба та морепродукти** — свіжий лосось-стейк або кілька креветок
3. **Молочні продукти та сири** — головка твердого сиру + трохи молока
4. **Овочі, зелень і гриби** — жмуток свіжої зелені або томат/цибуля
5. **Фрукти, ягоди та горіхи** — жменя ягід (напр. полуниці) або горіхи
6. **Крупи, борошно та сухі продукти** — купка борошна / зерно на ложці
7. **Хлібобулочні вироби** — свіжий багет або булочка з хрусткою скоринкою
8. **Соуси, спеції та приправи** — ложка спецій / баночка соусу
9. **Інше виробниче сировина** — нейтральний предмет (коробка/пакування)

## 4. Сигнатурний елемент (те, що зробить цей модуль впізнаваним)

Основний бренд додатку — холодний синій (`brand-500`). Щоб модуль
«Сировина» відчувався як «кухня/цех», а не як ще один синій адмінський
екран, додай **один** акцент: тонке тепле «пшеничне» amber-підсвічування
(`#C97C2B` / фон `#FBEBD7`) — застосовуй ЛИШЕ у двох місцях:
- тонке amber-кільце/облямівка навколо фото-мініатюри категорії при
  активному/tap-стані (замість звичного синього)
- фокус-стан поля пошуку на екрані замовлення (замість стандартного
  синього focus ring — тут теплий amber)

Більше ніде amber не використовується — це навмисно єдиний, стриманий
акцент-підпис, а не нова палітра.

## 5. Екран 1 — «Сировина для цеху» (список дій розділу)

Стек карток на всю ширину, кожна ~118px:

1. **Замовлення сировини** — активна, клікабельна. Замість емодзі 📋 —
   маленька іконка-фото (жмуток пшениці/зерна на brand-50 підкладці).
   Підпис «Створити заявку на потрібну сировину», стрілка `→` праворуч
2. **Брак сировини** — неактивна (приглушена), бейдж «скоро»
3. **Прихідні накладні** — неактивна, бейдж «скоро»
4. **Проблема з постачанням** — неактивна, бейдж «скоро»

```
│ Замовлення сировини          │

│                              │
│ ┌───────────────────────┐   │

│ ┌────────────┐┌────────────┐│
│ │[фото] М'ясо ││[фото] Риба ││
│ │та птиця     ││та море…    ││
│ └────────────┘└────────────┘│
│ ┌────────────┐┌────────────┐│
│ │[фото] Молоч.││[фото] Овочі││
│ └────────────┘└────────────┘│
│  … (5 рядів × 2, 9 плиток,   │

```

- Заголовок «Замовлення сировини» (h1) + підзаголовок «Знайдіть продукт
  або оберіть категорію»
- Поле пошуку на всю ширину, іконка лупи зліва, плейсхолдер «Пошук за
  назвою», висота ~48px. Зараз пошук неактивний (disabled/приглушений
  стан) — але верстай як звичайне повноцінне поле, просто в
  disabled-стані, а НЕ як «заглушку», бо скоро запрацює
- Сітка категорій: **2 колонки × 5 рядів**, 9 плиток + 1 порожня
  клітинка в кінці. Кожна плитка компактна й горизонтальна (НЕ
  квадратна), висота ~64-72px: фото-мініатюра зліва (див. п.3), назва
  категорії текстом праворуч (до 2 рядків, дрібний шрифт)
- Усе має влазити на екран 375×812 без скролу або з мінімальним
  прокручуванням — це швидкий робочий інструмент, не «галерея»

Список категорій (рівно ці 9, у такому порядку):
1. М'ясо та птиця
2. Риба та морепродукти
3. Молочні продукти та сири
4. Овочі, зелень і гриби
5. Фрукти, ягоди та горіхи
6. Крупи, борошно та сухі продукти
7. Хлібобулочні вироби
8. Соуси, спеції та приправи
9. Інше виробниче сировина

**Стани, які теж треба показати макетом:**
- *Loading:* поки фото категорій вантажаться — skeleton-плитки (сірий
  прямокутник-заглушка з м'яким pulse/shimmer, БЕЗ фото й тексту)
- *Active/pressed:* тонке amber-кільце навколо фото-мініатюри (п.4) +
  scale-down 97%

```

│ ← Назад                     │
│                              │
│ М'ясо та птиця               │
│                              │
│ ┌───────────────────────┐   │
│ │ Курка гриль        кг  │   │

│ │ Стейк яловичий      кг  │   │

└─────────────────────────────┘
```

- «← Назад», заголовок = назва категорії
- Вертикальний список товарів, рядок ~56px: назва товару зліва, одиниця
  виміру справа (кг / л / шт), тонка бордер-картка між рядками
- **Порожній стан** (для категорій, де ще немає товарів у базі — це
  реальний і частий сценарій зараз): НЕ просто сірий текст «немає
  товарів» по центру екрана — зроби це маленьким, спокійним empty-state
  з дружньою фразою від імені «Галі», напр. «Тут поки порожньо — товари
  з'являться, щойно їх додадуть у базу» + маленька ілюстрація/іконка
  (напр. відкрита коробка), у стилі решти додатку, без драматизму

## 8. Рух (motion) — за потреби показати анотацією на макеті

- Плитки категорій з'являються з легким fade-up і невеликим stagger
  (кожна на ~40-60ms пізніше попередньої) — вже так зроблено в іншіх
  екранах додатку, тримай той самий ритм
- Tap на будь-якому елементі: scale ~97%, без відскоку
- Ніякого зайвого руху понад це — інструмент для роботи, не промо-сайт

## 9. Що НЕ потрібно в макетах

- Кошик, кількість, підтвердження замовлення — цього функціоналу ще
  немає, макети лише для навігаційних екранів вище
- Фото самих товарів у списку категорії (екран 3) — там лише назва +
  одиниця виміру, без фото
- Десктопна/планшетна версія
- Темна тема (можна показати як бонус, не обов'язково)
- Нова кольорова палітра поза п.2 і п.4 — бренд уже живий у продакшені,
  amber-акцент єдиний дозволений відступ від нього
